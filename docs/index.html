Overview

Turn the College Board question bank into printable SAT practice sets. Pick assessment, section, domains, skills, difficulty, question count and batching rules, then render polished PDFs on your own machine. Local-first by default — no account, no hosting. An optional hosted path (Vercel frontend + Render worker) exists if you want it.

  • Node.js 20+, Playwright Chromium PDF render
  • Web UI + CLI (batch_export.mjs) — student / teacher / clean batches
  • Double-click launcher — launch.bat (Windows) / launch.command (macOS)

Not an official College Board project.

Quick start

Release build or local zip — double-click the launcher:

  • Windows: launch.bat
  • macOS: launch.command

Or run manually:

npm install
node node_modules/playwright/cli.js install chromium
npm start
# open http://localhost:4173
npm run export -- \
  --assessment "SAT" \
  --section "Math" \
  --domains "Algebra" \
  --skills "Linear functions" \
  --difficulty "Easy,Medium" \
  --question-count 20 \
  --chunk-size 10 \
  --mode student \
  --output ./output/math

Features

  • Lookup loading from the College Board question bank
  • Filters — section, domain, skill, difficulty, question count, batch size
  • Preview before export
  • Playwright-rendered PDFs — student / teacher / clean batches
  • Optional explanations appended per batch
  • Deduplication across machines
